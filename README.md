# 🧭 AstralForge Bounty Board

A modular, location-based bounty board system for Foundry VTT.

Players discover, accept, and complete sidequests organically through **taverns, inns, guild halls, and other in-world locations**—no immersion-breaking menus required.

---

## ✨ Features

- 📜 **Diegetic Quest Discovery**
  - Players interact with bounty boards in-world
  - Designed for taverns, inns, guild halls, temples, and black markets

- 🧩 **Modular Quest System**
  - Easily create, duplicate, and scale quests
  - Supports sandbox-style campaigns

- 🎯 **Accept & Track Quests**
  - Players can accept available jobs
  - GMs can complete and manage quest states

- 🔐 **Permission Layers**
  - Public notices vs hidden details
  - GM-only notes and outcomes

- 🧠 **World-State Driven**
  - Quests can evolve, expire, or escalate
  - Supports living world design

## ⚙️ Installation

### Option 1: Manifest URL (Recommended)

Paste this into Foundry's **Install Module** field:
https://raw.githubusercontent.com/MythicRealmsTTRPG/astralforge-bounty-board/main/module.json

---

### Option 2: Manual Install

1. Download the latest release `.zip`
2. Extract to:
FoundryVTT/Data/modules/astralforge-bounty-board

3. Enable the module in Foundry

## 🧱 How It Works

- Quests are stored internally within the module
- Players access them through a UI or (future) in-world interaction points
- Quests have states:
  - `available`
  - `accepted`
  - `completed`
